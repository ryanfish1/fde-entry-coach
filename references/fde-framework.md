# FDE Framework Reference

## Purpose

This file documents the conceptual sources and the operational interpretation used by `fde-entry-coach`.

The Skill is not a reproduction of any book. It converts broad FDE delivery ideas into a diagnostic and project-coaching workflow.

## Operational concepts used in this Skill

### PSF — Problem-Solution Fit

For a first project, score:

- Pain: 0–5
- Economics: 0–5
- Feasibility: 0–5

Interpretation:

- 12–15: good first project
- 9–11: narrow scope or remove a blocker
- 8 or below: do not build yet

### Five Maps

Before architecture, map:

1. Data
2. Workflow
3. Organization
4. System
5. Politics

For a portfolio project with limited enterprise access, use a minimum version with one real user, one real dataset, one real workflow, and one real metric.

### MVD — Minimum Viable Deployment

The smallest deployment that can prove real value in a real workflow.

Required fields:

- user
- workflow
- real data
- value metric
- quality threshold
- deadline
- graduation rule

### Activation over launch

A system being “online” is not sufficient. The project needs evidence that real users repeatedly complete the target workflow.

Maintain a friction log and prioritize blockers that prevent tomorrow's use.

### Asset extraction

Every deployment should produce reusable assets such as:

- checklist
- connector
- evaluation set
- prompt / policy
- workflow template
- deployment script
- monitoring pattern
- discovery questionnaire

A healthy FDE practice should reduce custom work on the next similar project.
